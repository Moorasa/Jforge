### 오케스트레이터 허브 API (P3-4/P3-5/P3-6이 그대로 참조 — 매우 중요)

`window.JWorks_JSForgeAdminStudio` 에 노출된 공개 인터페이스. 하위 모듈(팔레트/프리뷰/속성패널)은 이 허브에 구독·조회·갱신한다.

| 함수 시그니처 | 역할 |
|---|---|
| `onScreenLoaded(cb)` | 화면 단건 로드 완료 시 `cb(screen)` 호출 등록. `screen`은 `/api/screens/{id}` 응답 메타 객체(screenId/projectId/screenName/stem/archetypeCode/roleCode/statusCode 등). 체이닝용 `studio` 반환. |
| `onDefinitionChanged(cb)` | DEFINITION_JSON 변경 시 `cb(def, meta)` 호출 등록. `def`=현재 DEFINITION_JSON 객체, `meta`=`{reason}`(`"screenLoaded"`\|`"edit"` 등). 화면 로드 직후에도 1회 통지(`reason:"screenLoaded"`). |
| `getScreen()` | 현재 편집중 화면 메타 객체 반환(없으면 `null`). |
| `getDefinitionJson()` | 현재 DEFINITION_JSON 객체 반환(없으면 `null`). 단건 응답의 `definitionJson`(`@JsonRawValue`로 이미 JSON 트리)을 파싱 보관. |
| `updateDefinitionJson(def, meta)` | 하위 모듈(팔레트 P3-5 / 속성패널 P3-4)이 in-memory DEFINITION_JSON을 교체할 때 호출. dirty=true 세우고 `definitionChanged` 구독자에 통지. |
| `isDirty()` | 미저장 변경 여부. |
| `markSaved()` | 저장 완료(P3-6b) 후 dirty 해제. |

> pub/sub은 단순 콜백 배열(`subs.screenLoaded[]`/`subs.definitionChanged[]`)이며 구독자 예외는 try/catch로 격리한다. 상태는 모듈 내부 `state`(projectId/screen/definition/dirty) 단일 소유. P3-4는 `onDefinitionChanged`+선택 인스턴스 통지로, P3-5는 팔레트 클릭→`updateDefinitionJson`으로, P3-6는 `onDefinitionChanged`로 프리뷰 갱신에 붙는다.
