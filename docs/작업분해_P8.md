## 방향 확인 (원한 것 vs 확정 축 vs 채택한 절충)

| 원한 것 | 기존 확정 축과의 충돌 | 채택한 절충(P8) |
|---|---|---|
| 캔버스에 **드래그해서** 요소 배치 | 기획서 0장 2번: "자유 드래그 캔버스 아님" — 단, 이 축의 본질은 **자유 좌표 금지**(생성물이 MagicIAM 슬롯 구조에 결속)이지 드래그 제스처 금지가 아님 | **팔레트 → 캔버스 슬롯 드래그&드롭** 지원. 드롭 대상은 여전히 슬롯(후보 하이라이트). 자유 좌표 없음 → 계약·검증·골든 전부 무손상 |
| 각 요소의 **크기 제어** | 공통 런타임 CSS(§12) 고정 — 크기 자유도가 없었음 | **인스턴스 layout props**(`layoutWidthPct`/`layoutHeightPx`, §13 신설): 캔버스 리사이즈 핸들·속성패널 입력 → DEFINITION 영속 → **진짜 per-screen인 `{stem}List.css`에 조건부 산출**. 공통 CSS 무수정 |
| **공통 CSS를 요소별로 선택**해 정하고 싶음 | 공통 런타임은 번들 1벌(§12) — 화면별 수정 금지 | 요소별 결정은 **per-screen CSS**로 낙착(크기 §13 + 기존 styleClass 계열 props). 공통 CSS는 계속 공유 자산으로 보존(수정 시 전 화면 파급이라 의도적으로 봉인) |

> **미채택(명시)**: 절대좌표 자유 배치(요소를 임의 위치에 픽셀 단위로 놓기)는 생성 엔진이
> "슬롯 → 고정 마크업 include" 구조라서 채택하지 않았다. 이것이 진짜 필요하면 새 아키타입
> (예: FREE_CANVAS — absolute 컨테이너 + 인스턴스별 좌표 props)을 add-only로 설계하는
> 별도 페이즈가 필요하다(생성 템플릿·검증·golden 신규 세트).
